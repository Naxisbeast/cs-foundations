# Problem Solving

## My Beginner Programming Approach

When solving a beginner programming problem, I try to slow down and understand the task before writing code.

## 1. Understand The Problem

I first ask what the program is supposed to do in plain language.

Example: "The program must calculate whether a student passed based on a mark."

## 2. Identify Inputs

Inputs are the values the program needs.

Example:

- Student mark
- Account deposit amount
- File name

## 3. Identify Outputs

Outputs are the results the program should display or produce.

Example:

- Grade classification
- Updated balance
- Word count

## 4. Break The Problem Into Steps

I write the task as smaller steps:

1. Ask for input.
2. Validate the input.
3. Process the data.
4. Display the result.

## 5. Write Pseudocode

Pseudocode is a simple plan before real code.

```text
Ask for mark
If mark is invalid, show an error
If mark is 50 or more, show Pass
Otherwise, show Fail
```

## 6. Test Edge Cases

Edge cases are values that may break the program if I forget them.

Examples:

- Empty input
- Negative numbers
- Zero
- Very high values
- Missing files
- Withdrawing more money than the current balance
