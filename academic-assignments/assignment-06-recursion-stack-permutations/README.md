# Assignment 06: Recursion, Stack Tracing, And String Permutations

## Topic / Concept Focus

This learning exercise focused on recursion and stack-based tracing while generating permutations of a string.

## Task Summary

The task involved generating all permutations of a string using recursion. A stack was used to trace recursive calls and returns so that the flow of the recursive algorithm could be understood more clearly.

## Data Structures Or Algorithms Used

- Recursion
- Stack
- String permutation algorithm
- Recursive call tracing
- Backtracking-style thinking

## What I Learned

- How recursive methods break a problem into smaller versions of the same problem.
- Why base cases are important.
- How a stack can help explain recursive call flow.
- How permutations grow quickly as the input length increases.
