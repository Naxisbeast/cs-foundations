# Assignment 01: OOP Inheritance And Polymorphism

## Topic / Concept Focus

This learning exercise focused on object-oriented programming, especially inheritance, polymorphism, abstract methods, constructors, accessors, mutators, and `toString` methods.

## Task Summary

The task involved creating a superclass and two subclasses. The classes needed variables, constructors, getter and setter methods, `toString` methods, and abstract methods that the subclasses would implement.

A test program was used to demonstrate polymorphism by working with superclass references that could refer to subclass objects. It also showed how Java calls `toString` both explicitly and implicitly.

## Data Structures Or Algorithms Used

- Class hierarchy
- Inheritance
- Polymorphism
- Abstract methods
- Object arrays or references in the test program

## What I Learned

- How a superclass can define shared structure.
- How subclasses can extend and customise behaviour.
- How polymorphism lets one reference type work with different object types.
- Why `toString` is useful for readable object output.
