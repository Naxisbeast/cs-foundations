# Assignment 02: OOP Arrays, Sorting, And Complexity

## Topic / Concept Focus

This learning exercise extended object-oriented programming work by adding arrays, random object creation, sorting, and time complexity analysis.

## Task Summary

The task built on the previous inheritance and polymorphism assignment. It involved randomly creating subclass objects, storing them in an array, sorting the array, and explaining the performance of the sorting approach.

The complexity discussion included tau notation, simplified analysis, and Big-O notation.

## Data Structures Or Algorithms Used

- Arrays
- Objects and subclass instances
- Sorting algorithm
- Time complexity analysis
- Big-O notation

## What I Learned

- How arrays can store related objects.
- How polymorphism still applies when objects are stored together.
- How sorting changes the order of data based on a comparison rule.
- How to move from detailed operation counting to simplified Big-O analysis.
